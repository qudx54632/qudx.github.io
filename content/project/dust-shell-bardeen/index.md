This Julia implementation evolves a fixed-shell Bardeen dust-shell model and produces diagnostic plots for testing gauge consistency and effective quantum-gravity dynamics.

The code accompanies the manuscript [Consistent Gauge Conditions for Dust-Shell Dynamics in Effective Quantum Gravity](https://arxiv.org/abs/2603.24168) and includes the evolution, boundary, initial-data, and plotting routines used in the analysis.
