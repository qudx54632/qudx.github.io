# Personal Academic Website

This repository contains the source code for my personal academic website, built using **Hugo** and the **HugoBlox (Academic)** framework.  
The website hosts my research profile, publications, projects, teaching materials, and professional activities.

## 📁 Repository Structure

```
.
├── assets/        # Custom CSS, JS, and assets
├── config/        # Site configuration files
├── content/       # Main website content
│   ├── authors/       # Author profile
│   ├── event/         # Talks and events
│   ├── post/          # Blog posts
│   ├── project/       # Research projects
│   ├── publication/   # Publications
│   └── teaching/      # Teaching materials
├── layouts/       # Custom layout templates
├── static/        # Static files (images, PDFs, etc.)
├── go.mod         # Hugo module file
├── hugoblox.yaml  # HugoBlox configuration
├── netlify.toml   # Deployment configuration (optional)
├── LICENSE.md
└── README.md
```

---

## ✏️ Editing Content

Most website content is written in **Markdown** inside the `content/` directory.

Examples:

- Add a new project  
  `content/project/`

- Add a publication  
  `content/publication/`

- Add a teaching page  
  `content/teaching/`

Each folder contains an `_index.md` file or individual Markdown files that define pages.

---

## 🚀 Deployment

The website is deployed using **GitHub Pages**.

To update the site:

```
git add .
git commit -m "Update website content"
git push
```

After pushing, GitHub Pages will rebuild and publish the site automatically.
